# Desktop agent tools preview

GrokDeck 0.3.0 preview adds a native-app computer viewer on Windows and macOS, with mouse and keyboard control enabled on opening, a full-screen button, and an Open in Grok Bot fallback. The screen uses the existing bounded, account-scoped viewer relay. Vendor screen credentials remain in the local helper. Closing or hiding the viewer disconnects it. The Computers page can explicitly start or resume a computer; this may use the account's resources.

Edit agent opens current name, title and description. Save is explicit and checks the original values before writing, then reads them back. Images selected by the user are converted to bounded PNG thumbnails; removing a custom image is also explicit. If a multi-part profile/image save cannot be confirmed, the editor warns that part may already have saved rather than automatically retrying.

Overview shows pinned agents first and the remaining agents by Grok Bot group. Drag onto a row to insert before it, or onto a group to append. Right-click or use Move / pin for accessible group moves and pinning. New group, Rename and Delete group edit the shared sidebar; deleting a group never deletes its agents. All agents offers name/activity/group sorting and status/group filters.

Group and pin changes sync to Grok Bot, not a separate local layout. The helper reads gateway host settings and backend runtime settings; it writes only sidebar sections and pins. Writes check a fresh baseline and read back both stores. These are separate vendor operations, not an atomic transaction: concurrent changes or a failed second write can leave a partial result. The UI reloads and warns instead of silently retrying. Editing is disabled until a live synchronized layout is available.

Verified locally: automated gateway, conflict, image validation and UI tests; a real empty group create/rename/delete round trip; and a dedicated test agent title edit/read-back/restore. The desktop viewer rendered a real 1920×1200 computer screen without sending input; a simulated RFB connection and control toggling also passed. Two other agents reported running but returned HTTP 502 from their screen endpoints, so the Grok Bot fallback remains important. Actual Windows account verification remains a separate device check. No general agent permission, billing, sharing or automation editor is included.
